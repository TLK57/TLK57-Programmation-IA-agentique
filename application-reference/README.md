# Application de référence

L'application développée **à la main**, qui sert de point de comparaison.

À renseigner :
- Nom et origine (quel projet, quelle année, qui l'a développée)
- Pile technique
- Comment l'installer et la lancer
- Ses mesures de référence (voir `evaluation/grille-evaluation.md`)

Placer le code dans ce dossier (ou ajouter un lien vers son dépôt d'origine).
